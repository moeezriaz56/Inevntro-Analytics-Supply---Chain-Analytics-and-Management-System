# Inevntro-Analytics-Supply---Chain-Analytics-and-Management-System
Python-based POS and inventory management system featuring a closed-loop data pipeline for real-time supply chain tracking and automated BI profit analysis.
Ideated and engineered a comprehensive Python-based inventory and Point-of-Sale (POS) application designed to digitize and optimize the manual supply chain operations of a high-footfall retail business.
Architected a closed-loop data engineering pipeline using Pandas and NumPy to automate read/write operations across interconnected databases for real-time product tracking, sales transactions, and customer loyalty data.
Integrated a dynamic Business Intelligence module that triggers automated low-stock supply chain alerts, generates real-time profit analysis, and visualizes retail performance metrics.
